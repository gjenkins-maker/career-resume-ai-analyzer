# AI-Powered Career & Resume Analyzer

This project is an interactive Streamlit app that analyzes a user's resume and provides career recommendations, skill insights, and resume improvement suggestions.

## Features
- Resume PDF upload
- Resume text extraction
- Skill strength visualization
- Suggested career paths
- Resume improvement tips

## Tools Used
- Python
- Streamlit
- Pandas
- Plotly
- PyPDF2
- OpenAI

## Purpose
The goal of this project is to combine business analytics, artificial intelligence, and data visualization to help users better understand their career strengths and areas for improvement.
